# RESULTS.md — ART-AI RL, honest before/after

All "after" numbers were generated by `python -m experiments.run_all` (20 independent
seeds x 800 training episodes, `max_steps=15`, master seed 12345). Raw data:
`backend/experiments/results/{results.csv,results.json,run_meta.json,learning_curves.png}`.
The "before" numbers are from the shipped `backend/test_rl_learning.py`, run as-is.
Every number here was produced on this machine; none is asserted.

## The headline

| agent | win rate | mean return | regret vs optimum | steps-to-admin |
|---|---|---|---|---|
| **before** — old "optimized" agent (`test_rl_learning.py`) | **2%** | — | — | 22.0 |
| before — random (same old test) | 49% | — | — | 16.7 |
| after — random baseline | 0.171 ± 0.012 | −0.003 ± 0.008 | 0.680 ± 0.008 | 11.5 |
| after — greedy-by-signal baseline | 0.999 ± 0.001 | 0.655 ± 0.002 | 0.022 ± 0.002 | 7.49 |
| **after — fixed Q-learning agent** | **0.960 ± 0.035** | **0.631 ± 0.031** | **0.047 ± 0.031** | 7.43 |
| after — value-iteration optimum (ceiling) | — | 0.677 | 0.000 | ~7 |

The fixed agent reaches **96% win rate** and a return that is **93% of the exact
optimum** (regret 0.047), versus a random agent at 17% win rate and essentially zero
return. The pre-fix "optimized" agent scored **2%** and lost to random. The Q-table grew
from **~9 entries to ~60** (mean 59.95 ± 1.77), reflecting a state space the policy can
actually use.

> Why the two rows use different environments: the *old* environment was itself part of
> the defect (4-state, non-Markovian, positive self-loop, reward-hacked — see
> `RESEARCH_NOTES.md`). The "before" row documents that broken system on its own test;
> the "after" rows are the corrected, grounded, fully-specified MDP that admits an exact
> optimum to measure against. They are not the same MDP, and the point of the work is
> precisely that the old one could not be made research-grade by more training.

## What was wrong and what changed (summary; full detail in RESEARCH_NOTES.md)

1. **State = access level only (4 states).** A no-op `lateral_movement` at `internal`
   produced `next_state == state` with positive reward, so its Q-value diverged upward
   (observed Q≈90.9) and the greedy policy looped forever without escalating to ADMIN.
   → **Fixed:** state now encodes `(access, position, discovered-hosts)` with a
   documented key; non-progressing actions cost a step and pay no positive reward, so
   there is no self-loop to over-reinforce.
2. **Reward hacking.** The `+100 / +120` Exploit-DB "hint" bonus dwarfed the ~15–60 for
   actually reaching ADMIN. → **Fixed:** base reward is only a bounded step cost
   (−0.01) plus a terminal goal (+1.0). The hint is measured only as an ablation and is
   never in the reward.
3. **Magic-number dynamics.** `SUCCESS_PROBABILITIES` and hint confidences were
   hand-tuned literals. → **Fixed:** per-host probabilities are derived in
   `experiments/grounding.py` from the CVSS v3.1 exploitability sub-score (official
   metric weights), EPSS, the Exploit-DB verified flag, and patch age, via one
   documented formula, clamped to [0.05, 0.95]:

   | host | foothold p | privesc p |
   |---|---|---|
   | juice-shop | 0.810 | 0.126 |
   | dvwa | 0.536 | 0.384 |
   | flask-api | 0.216 | 0.508 |

   The asymmetry (cheap foothold host is a poor escalation host) is what makes the
   optimal policy non-trivial: recon, take the cheap foothold on juice-shop, then
   escalate — the value-iteration optimum stops reconning at dvwa because the extra
   recon cost to reach flask-api's stronger privesc is not worth it under discounting.

## Ablations (each is a number with a CI, not an assertion)

Default agent = double-Q **on**, replay **on**, ε-greedy, hint **off**. Each ablation
flips one switch. Metrics over 20 seeds; final-policy regret (lower is better) and
sample efficiency (episodes to reach 80% greedy win rate, lower is better):

| configuration | regret vs optimum | episodes-to-80%-win | final win rate |
|---|---|---|---|
| q_learning (default) | 0.047 ± 0.031 | 36.3 ± 8.0 | 0.960 ± 0.035 |
| double-Q **off** | 0.031 ± 0.027 | 28.8 ± 5.7 | 0.976 ± 0.029 |
| replay **off** | 0.036 ± 0.030 | **73.8 ± 22.9** | 0.973 ± 0.033 |
| Boltzmann (vs ε-greedy) | 0.028 ± 0.021 | 33.8 ± 8.7 | 0.973 ± 0.027 |
| hint **on** | 0.034 ± 0.020 | 30.0 ± 6.1 | 0.978 ± 0.027 |

Honest reading of these numbers:

- **Experience replay significantly improves sample efficiency.** Turning it off pushes
  episodes-to-80% from ~36 to ~74 (CIs [28,44] vs [51,97] do not overlap) — replay
  roughly halves the episodes needed to become competent. It does **not** significantly
  change final policy quality.
- **Double-Q does not help here.** Its final-regret and sample-efficiency deltas versus
  default are within overlapping CIs; if anything it is marginally slower. This is
  expected: double-Q addresses maximization bias, which is minor on a small MDP with
  modest stochasticity. Keeping it is not justified by a measured benefit on this task.
- **Boltzmann vs ε-greedy: no significant difference** in final quality or sample
  efficiency (all CIs overlap).
- **The hint (a domain-knowledge exploration prior) modestly speeds early learning**
  (~30 vs ~36 episodes) but the difference is within noise, and by construction it
  cannot change the converged policy (it only biases exploration, never the reward or
  the Q target). So "the librarian hint helps" is, at best, a small and not-clearly-
  significant sample-efficiency effect — not the dominant driver the old +100 reward
  bonus made it look like.
- **A domain heuristic is already near-optimal on this MDP.** `greedy-by-signal`
  (regret 0.022) slightly edges the trained agent (0.047). This is honest and expected:
  on a small, well-understood MDP a good hand rule is hard to beat; the value of
  *learning* shows up when the dynamics are larger or unknown. We report it rather than
  hide it.

**Net:** the only technique with a statistically defensible benefit on this task is
experience replay (sample efficiency). Double-Q, Boltzmann, and the hint are not
justified by a significant improvement here, and we say so.

## Exact commands run

```bash
cd art-ai/backend
python test_rl_learning.py                 # before: RL 2% vs random 49%
python -m experiments.grounding            # grounded per-host probabilities
python -m experiments.value_iteration      # V*(initial) = 0.6772, optimal policy trace
python -m experiments.run_all              # after: full 20-seed x 800-episode harness
```

Seed, derived seed list, git commit, config, and library versions for the "after" run
are recorded in `backend/experiments/results/run_meta.json`.
